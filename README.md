## Local lens

Travellers	can't	plan	trips that	are	safe,	affordable	and authentic.

Project Description

LocalLens helps a traveller build a personalised journey instead of simply searching through a list of tourist places. Users can enter their budget, available time, interests and preferences. The platform provides a budget-aware itinerary, estimated costs, verified local connections, bus and train options, and safety or weather alerts. It also shows how the selected plan supports local providers. For tourism authorities, the platform can provide actionable feedback about safety, accessibility and visitor experience.

## Installation Steps
How to run your project locally:
To run your Local Lens project locally, clone the codebase from your repository, navigate into the project directory, and install its packages using npm install (or your preferred package manager). Next, set up a .env.local file in the root directory to store required environment variables, including your GEMINI_API_KEY to power the AI grounding and decision engine features. Finally, start your local development server with npm run dev (or npm start) and open http://localhost:3000 (or the port specified in your terminal) in your browser to view and test the application

git clone [https://github.com/adisankar20247-lab/odyssey.git]

# 2. Navigate to the project directory
cd odyssey

# 3. Install dependencies
npm install  # or 'pip install -r requirements.txt'

# 4. Set up environment variables
# Create a .env file and add your Google AI API keys

# 5. Run the application
